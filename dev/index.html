Lightcurves.jl

Rotational light curves and phase curves of small Solar System bodies: asteroids, Centaurs and trans-Neptunian objects.

The package is being rebuilt (towards version 0.1.0, November 2026). The current core covers the analysis of sparse and dense photometry:

TaskFunctions
period searchgls, falc, falc_fit, frequency_grid, spectral_window, permutation_fap
folded light curvesfold, fourier_fit, split_halves
phase curvesreduced_magnitude, fit_phase_curve, ps1_to_V
physical quantitiesgeometric_albedo, diameter, ellipsoid_amplitude
statisticschi2_cdf

Only the Julia standard library is required. Phase dispersion minimisation (PDM) is provided by the separate package AstroPDM.jl.

using Lightcurves
f = frequency_grid(t; fmin=24 / 100, fmax=24 / 2)       # t in days → periods 2–100 h
p = gls(t, mag, f; σ=err)
χ2, χ0 = falc(t, mag, f; σ=err, order=2, groups=night)
P = 1 / f[argmin(χ2)]                                    # days
fit = falc_fit(t, mag, 1 / P; σ=err, groups=night)
fit.amplitude
