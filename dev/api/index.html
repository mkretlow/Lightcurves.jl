API

Lightcurves — Module
Lightcurves

Rotational light curves and phase curves of small Solar System bodies (asteroids, Centaurs, TNOs).

  • Period search: generalised Lomb–Scargle (gls), FALC Fourier-series χ² scan (falc, falc_fit), spectral window (spectral_window), frequency grids (frequency_grid), permutation false-alarm probabilities (permutation_fap).

  • Folding: fold, Fourier fits (fourier_fit), split-halves test (split_halves).

  • Phase curves: reduced magnitudes (reduced_magnitude), linear phase-curve fit with band offsets and clipping (fit_phase_curve), photometric transformations (ps1_to_V).

  • Physical quantities: geometric albedo and diameter (geometric_albedo, diameter), light-curve amplitude of a triaxial ellipsoid (ellipsoid_amplitude).

  • Period fit with the period free (fit_period, result PeriodFit), Fourier-order scan, phase ephemeris.

  • File formats: ALCDEF (read_alcdef, write_alcdef), CdR / CourbRot (read_cdr); MPC band corrections (mpc_to_V); light-time correction.

  • Data access: MPC observations (fetch_mpc_photometry), JPL Horizons geometry (observing_geometry), JPL SBDB (fetch_sbdb), ALCDEF light curves (fetch_alcdef), LCDB (lcdb_entry, fetch_lcdb_member, read_lcdb_summary).

  • CCD images: reduction (masterframe, calibrate), star detection (findstars), centroids, aperture photometry (aperture, instrumental_magnitude), FWHM, frame offsets and a simple plate match (platematch); FITS reading (readfits) with using FITSIO (package extension).

  • Plot recipes for Plots.jl: plot(::PeriodFit) (phased light curve, Minor Planet Bulletin style), plot(::Vector{ALCDEFBlock}), periodogramplot, phasecurveplot, splithalvesplot, windowplot.

Light dependencies only (RecipesBase, JSON, CodecZlib and standard libraries). PDM: package AstroPDM.jl.

Author: Mike Kretlow <mike@kretlow.de>

Period search

Lightcurves.frequency_grid — Function
frequency_grid(t; fmin, fmax, oversample=10) -> Vector{Float64}

Evenly spaced trial frequencies from fmin to fmax (cycles per unit of t) with step 1 / (oversample * T), where T is the time span of t. For rotation periods in hours, e.g. fmin = 24 / 100, fmax = 24 / 2 with t in days.

source
Lightcurves.gls — Function
gls(t, y, f; σ=nothing) -> Vector{Float64}

Generalised Lomb–Scargle periodogram with a floating mean (Zechmeister & Kürster 2009, A&A 496, 577): normalised power p(f) ∈ [0, 1] = 1 − χ²(f)/χ²₀ of a weighted sinusoid plus constant, for the trial frequencies f. σ are the measurement errors (equal weights if omitted).

source
Lightcurves.falc — Function
falc(t, y, f; σ=nothing, order=2, groups=nothing) -> (χ², χ²₀)

FALC period scan (Harris et al. 1989, Icarus 77, 171): at each trial frequency a Fourier series of the given order is fitted by weighted least squares together with one free zero point per group (groups: e.g. night, station or band labels; one common zero point if omitted). Returns the χ² for each frequency and χ²₀ of the zero points alone; the best frequency minimises χ². For a double-peaked asteroid light curve use order ≥ 2 and expect the rotation frequency, not twice it.

source
Lightcurves.falc_fit — Function
falc_fit(t, y, f; σ=nothing, order=2, groups=nothing) -> NamedTuple

The FALC model at one frequency f: (zero_points, groups, a, b, cov, chi2, amplitude, model), where a[k], b[k] are the cosine and sine coefficients, amplitude the peak-to-peak amplitude of the Fourier series and model(phase) the series (without zero point) as a function of the rotational phase phase = f t mod 1.

source
Lightcurves.spectral_window — Function
spectral_window(t, f) -> Vector{Float64}

Spectral window |Σ exp(2πi f t)|² / N² of the sampling times t at the frequencies f (1 at f = 0). Peaks of a periodogram that coincide with peaks of the window (e.g. 1 cycle per sidereal day, 1.0027 c/d) are aliases.

source
Lightcurves.permutation_fap — Function
permutation_fap(stat, t, y, f; nperm=100, groups=nothing, rng=Random.default_rng(), kw...) -> Float64

False-alarm probability of the maximum of the periodogram function stat(t, y, f; kw...) (e.g. gls) by permutation: y is shuffled nperm times (within each group, if groups is given) and the fraction of shuffles whose maximum reaches the observed one is returned. Caution: shuffling single points ignores correlated errors (e.g. nightly zero points); with sparse survey data the FAP is then too optimistic — shuffle nightly means or use groups = nights.

source
Lightcurves.fourier_fit — Function
fourier_fit(phase, y; σ=nothing, order=2) -> NamedTuple

Weighted least-squares Fourier series c₀ + Σₖ aₖ cos(2πk φ) + bₖ sin(2πk φ) in the rotational phase φ: (c0, a, b, cov, chi2, dchi2, amplitude, model), where dchi2 is the χ² improvement over a constant and model(φ) the fitted series including c0.

source
Lightcurves.split_halves — Function
split_halves(t, y, P; σ=nothing, nbins=10, t0=minimum(t), minpoints=2) -> NamedTuple

Split-halves test (Harris et al. 2014, Icarus 235, 55, Fig. 3): the light curve is folded at P, and the first (φ < 0.5) and second half are binned in nbins bins of the phase within the half-cycle. Returns (chi2, dof, p, centers, mean1, err1, mean2, err2): χ² of the differences of the weighted bin means, its degrees of freedom (bins with ≥ minpoints points in both halves) and the p-value. Similar halves (large p) mean that P/2 describes the data as well; different halves (small p) that the full period P is needed (e.g. two different maxima of a double-peaked light curve). A symmetric double-peaked light curve gives similar halves too.

Phase curves

Lightcurves.reduced_magnitude — Function
reduced_magnitude(m, r, Δ) -> m − 5 log10(r Δ)

Magnitude reduced to unit heliocentric (r) and geocentric (Δ) distance [au].

source
Lightcurves.fit_phase_curve — Function
fit_phase_curve(α, mred; σ=nothing, bands=nothing, ref=nothing, beta=nothing, clip=3.0, maxiter=10) -> NamedTuple

Linear phase curve mred = H + β α + offset(band) by weighted least squares with iterative clip·σ clipping (σ rescaled by the reduced χ² when it exceeds 1). α is the solar phase angle [deg], mred the reduced magnitude (reduced_magnitude). With bands (labels per point) one offset per band relative to the reference band ref (default: the first label) is fitted, so H refers to ref. beta fixes the phase coefficient [mag/deg]. Returns (H, H_err, beta, beta_err, offsets::Dict, offset_errs::Dict, keep, chi2_red, residuals); errors are scaled by √max(χ²_red, 1). Suited to the small phase angles of distant objects (α ≲ 2°), where the H–G system is not appropriate.

source
Lightcurves.ps1_to_V — Function
ps1_to_V(r, g_r; g_r_err=0.0) -> (V, V_err)

Johnson V from Pan-STARRS1 r and g − r: V = r + 0.006 + 0.474 (g − r) (Tonry et al. 2012, ApJ 750, 99, Table 6; scatter 0.012 mag, included in V_err together with the propagated colour error).

Physical quantities

Lightcurves.geometric_albedo — Function
geometric_albedo(H, D; H_err=0.0, D_err=0.0) -> (p, p_err)

Geometric albedo from the absolute magnitude H (in the band of the albedo, usually V) and the diameter D [km]: p = (1329 km / D)² 10^(−0.4 H), with first-order error propagation.

source
Lightcurves.diameter — Function
diameter(H, p; H_err=0.0, p_err=0.0) -> (D, D_err)

Diameter [km] from H and the geometric albedo p: D = 1329 km / √p × 10^(−H/5).

source
Lightcurves.ellipsoid_amplitude — Function
ellipsoid_amplitude(a, b, c, θ) -> Δm [mag]

Peak-to-peak light-curve amplitude of a triaxial ellipsoid with semi-axes a ≥ b ≥ c (rotation about c), seen at the aspect angle θ [rad] between the spin axis and the line of sight, at zero phase angle (geometric scattering): Δm = 2.5 log10(a/b) − 1.25 log10[(a² cos²θ + c² sin²θ) / (b² cos²θ + c² sin²θ)] (e.g. Binzel et al. 1989, Asteroids II). Equator-on (θ = π/2): 2.5 log10(a/b); pole-on (θ = 0): 0.

Period fit and light-curve model

Lightcurves.PeriodFit — Type
PeriodFit

Result of fit_period (or lightcurve_fit at a fixed period). Fields: period, period_err [same unit as the times; NaN if the period was fixed], order, a, b (Fourier coefficients), zero_points, groups (group labels in order), labels (display labels of the groups), chi2, dof, chi2_red, amplitude (peak-to-peak of the Fourier series), t0 (epoch of phase 0), tmin and tmax (first times after t0 of minimum magnitude, i.e. maximum brightness, and of maximum magnitude), and the data t, y, σ, g (group index per point). Plot it with plot(fit) (phased light curve in the style of the Minor Planet Bulletin; needs Plots.jl).

source
Lightcurves.fit_period — Function
fit_period(t, y, P0; σ=nothing, order=4, groups=nothing, labels=nothing, t0=minimum(t), search=0.02, object="") -> PeriodFit

Least-squares fit of a Fourier series of the given order with the period free, starting from P0 (same unit as t; for asteroid light curves t in days, light-time corrected) and one zero point per group (session, night, set of comparison stars). The Fourier coefficients and zero points are solved linearly at each trial period (variable projection); the period minimises χ² within P0 (1 ± search). The period error follows from the curvature of χ²(P), scaled by the reduced χ² (as for an unweighted or poorly weighted fit; Harris et al. 1989). Equivalent to the CdR / FALC fit with the period as a free parameter.

source
Lightcurves.lightcurve_fit — Function
lightcurve_fit(t, y, P; σ=nothing, order=4, groups=nothing, labels=nothing, t0=minimum(t), object="") -> PeriodFit

Fourier fit of the light curve at the fixed period P (no period error), e.g. to plot a light curve folded at a trial period.

File formats and corrections

Lightcurves.ALCDEFBlock — Type
ALCDEFBlock

One ALCDEF light-curve block (ALCDEF standard v2.3, Warner et al.): meta, the keyword/value pairs of the metadata section in file order (keywords may repeat, e.g. EQUINOX), and the data columns jd (UT Julian date of mid-exposure), mag and err (NaN if not given). block["KEYWORD"] returns the first value of a keyword or nothing; block["KEYWORD", default] with a default.

source
Lightcurves.read_alcdef — Function
read_alcdef(file_or_io) -> Vector{ALCDEFBlock}

Read all light-curve blocks of an ALCDEF file (STARTMETADATA … ENDMETADATA, DATA=JD|MAG[|MAGERR[|AIRMASS]] … ENDDATA). Blocks without ENDDATA (as in the ALCDEF bulk archive) end at the next STARTMETADATA or at the end of the file. The data delimiter is taken from the DELIMITER keyword (PIPE, SEMIC, TAB; COMMA and SPACE of the simple ALCDEF are accepted); CRLF line ends and blank lines are tolerated.

source
Lightcurves.write_alcdef — Function
write_alcdef(file_or_io, blocks)

Write ALCDEF light-curve blocks (metadata in the stored order, data with the PIPE delimiter; DELIMITER=PIPE is enforced). Errors that are NaN are omitted.

source
Lightcurves.alcdef_table — Function
alcdef_table(blocks) -> NamedTuple

All data points of a set of ALCDEF blocks as columns (jd, mag, err, session), where session is the block index (use it as groups in falc / fit_period for differential magnitudes with one zero point per session), and labels, one label per block ("SESSIONDATE CONTACTNAME").

source
Lightcurves.read_cdr — Function
read_cdr(file) -> NamedTuple

Read a light-curve file in the CdR (CourbRot) format of R. Behrend (header lines with three-letter keywords FMT, NOM, MES, POS, TEL, …, then whitespace-separated data; lines starting with # or ; are comments, e.g. rejected points). The FMT string gives the column meaning; D (date, JD) and V (target magnitude) are required, R columns are magnitudes of comparison stars. POS p e gives the time stamp position (−1 start, 0 middle, +1 end of the exposure) and the exposure time e [s]; returned times are mid-exposure. Returns (jd, mag, dmag, comps, object, observer, header::Dict, columns::Vector{Vector{String}}), where comps is the matrix of comparison-star magnitudes (one column per R) and dmag the differential magnitude V − mean(R) (equal to mag without R columns), as in the CdR / AsPyLib light-curve tools.

source
Lightcurves.light_time_correct — Function
light_time_correct(jd, Δ) -> jd − Δ τ_au

Times corrected for the light travel time from the object (geocentric distance Δ [au]) to the observer.

source
Lightcurves.MPC_BAND_TO_V — Constant
MPC_BAND_TO_V

Approximate corrections to the V band used by the Minor Planet Center for reported magnitudes, V = m + Δ(band) (average asteroid colours; e.g. "R" → +0.4, "G" (Gaia) → +0.28, "w" (Pan-STARRS) → −0.13). A blank band is "". For objects with known colours use a proper transformation (e.g. ps1_to_V) or fit band offsets (fit_phase_curve).

source
Lightcurves.mpc_to_V — Function
mpc_to_V(mag, band) -> V

V magnitude from an MPC-reported magnitude with the band corrections MPC_BAND_TO_V. Pan-STARRS bands reported as "Pg", "Pr", "Pw", … are mapped to "g", "r", "w", ….

CCD images and aperture photometry

Lightcurves.readfits — Function
readfits(file; hdu=nothing) -> (img::Matrix{Float64}, header)

Read a two-dimensional FITS image as img[x, y] (FITS axis order) with its header. hdu selects the HDU (1-based); by default the first HDU that holds a 2-D image, so tile-compressed (fpack) files work too. The header is a FITSIO.FITSHeader (header["DATE-OBS"]).

source
Lightcurves.robust_stats — Function
robust_stats(v) -> (level, σ)

Robust level and scatter of the values v: median and 1.4826·MAD, recomputed once after clipping at 3σ. Used for the image background and the sky annulus.

source
Lightcurves.masterframe — Function
masterframe(frames) -> Matrix{Float64}

Pixel-wise median of a stack of frames (bias, dark or flat). frames is a vector of equally sized matrices or of FITS file names (the latter needs FITSIO.jl, see readfits).

source
Lightcurves.calibrate — Function
calibrate(img; bias=nothing, dark=nothing, flat=nothing) -> Matrix{Float64}

Basic CCD reduction $(\mathrm{img} - \mathrm{bias} - \mathrm{dark}) / (\mathrm{flat}/\mathrm{median(flat)})$. dark is a bias-subtracted dark scaled to the exposure time of img; flat a bias- (and dark-) subtracted flat field, normalised here by its median. Each frame may be omitted.

source
Lightcurves.findstars — Function
findstars(img; nsigma=5.0, fwhm=3.0, border=8) -> Vector{(x, y, peak)}

Star detection: local maxima of the 3×3 box-smoothed image that lie nsigma·σ (σ of the 3×3 mean) above the robust background (robust_stats) and are separated by at least fwhm pixels; pixels within border of the edge are skipped. Returns named tuples (x, y, peak) (integer pixel positions, peak above background in the smoothed image), brightest first. Refine the positions with centroid.

source
Lightcurves.centroid — Function
centroid(img, x, y; r=4, iter=10, tol=0.01, maxshift=r, onfail=:nan) -> (x, y, status)

Intensity-weighted centroid within radius r around the current position, after subtracting the median of a ring (r + 2 … r + 6 px), iterated until the shift per step is below tol px in both coordinates.

status tells whether the fit succeeded:

  • :ok: converged within maxshift of the start position;
  • :edge: the box (radius r + 6) leaves the image, or the start position is not finite;
  • :noflux: no pixel above the ring median (blank sky);
  • :runaway: the centroid moved more than maxshift px from the start position (in total, not per step), e.g. a faint or empty position drifting onto a brighter neighbour;
  • :maxiter: not converged after iter iterations.

On failure the returned position is NaN by default (onfail=:nan), so that an unchecked failure cannot pass as a measured position; onfail=:start returns the start position and onfail=:last the last iterate instead (the status still reports the failure). xc, yc = centroid(...) ignores the status.

source
Lightcurves.aperture — Function
aperture(img, x, y; r=4.0, rin=8.0, rout=13.0, gain=1.0)
    -> (flux, σflux, sky, σsky, npix)

Circular aperture photometry at (x, y) with radius r and a sky annulus rin … rout (pixels). Pixels cut by the aperture edge are weighted by their covered fraction (5×5 sub-pixel sampling). The sky level is the robust median of the annulus (robust_stats). Flux and sky in ADU; npix the effective aperture area.

The error combines the photon noise of the source (gain in e⁻/ADU), the measured sky scatter per pixel (which includes read noise) and the error of the mean sky level (Howell, 1989): $σ^2 = F/g + n_\mathrm{pix}σ_\mathrm{sky}^2 + n_\mathrm{pix}^2σ_\mathrm{sky}^2/n_\mathrm{sky}$. Returns NaN flux if the position is not finite (e.g. a failed centroid), the aperture leaves the image or the annulus has fewer than 10 pixels.

    -> (A, t, nmatch, pairs)
