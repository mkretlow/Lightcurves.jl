Data access

All functions send only the object designation (no user information). The local databases (ALCDEF archive, LCDB release) are kept in datadir (ENV["LIGHTCURVES_DATA"] or the package's data/ folder); other downloads are cached in cachedir (ENV["LIGHTCURVES_CACHE"] or ~/.cache/Lightcurves.jl).

SourceFunctionsNotes
MPC observations APIfetch_mpc_observations, fetch_mpc_photometryall observations in ADES form; photometry with band and error. Band corrections to V: mpc_to_V
JPL Horizonsfetch_horizons_geometry, observing_geometryr, Δ, phase angle, predicted V; interpolated to the observation times
JPL SBDBfetch_sbdborbit and physical parameters (H, diameter, albedo, rotation period)
ALCDEF (alcdef.org)alcdef_sessions, fetch_alcdef, read_alcdef, write_alcdef; local archive: fetch_alcdef_archive, alcdef_archive_objects, read_alcdef_archiveper object through the web interface, or from the full archive (≈ 135 MB, one file per object). The blocks contain the observers' contact information
LCDB (Warner et al.)lcdb_entry, fetch_lcdb_archive, fetch_lcdb_member, read_lcdb_summary, lcdb_lookupone object from its ALCDEF page, or the tables of the release zip (40 MB; local copy, or single members by HTTP range requests)
CdR / CourbRot filesread_cdrR. Behrend's light-curve format

The ALCDEF format follows the ALCDEF standard v2.3 (Warner et al., 2024); the LCDB is described by Warner et al. (2009).

using Lightcurves
ph  = fetch_mpc_photometry("612533")                       # MPC magnitudes
geo = observing_geometry("612533", ph.jd)                   # r, Δ, α from Horizons
blocks = fetch_alcdef("1486")                               # ALCDEF light curves
tab = alcdef_table(blocks)
lcdb = lcdb_entry("1486"); lcdb["Period"]
